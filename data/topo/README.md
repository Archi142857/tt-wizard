# 수치지형도 (국토지리정보원)

`scripts/dem_from_contours.py` 가 읽는 원자료. 국토정보플랫폼(https://map.ngii.go.kr) 공간정보받기에서
캠퍼스를 영역으로 골라 받은 수치지형도 Ver2.0(SHP) 압축 파일을, 파일마다 폴더를 만들어 풀었다.
압축 파일에는 레이어가 60여 개 들어 있지만 저장소에는 스크립트가 쓰는 세 레이어만 올린다(`.gitignore`).

| 파일 | 내용 | 쓰는 곳 |
| --- | --- | --- |
| `*_F0010000.*` | 등고선 (`등고수치`, 5 m 간격) | DEM |
| `*_F0020000.*` | 표고점 (`수치`) | DEM, 1:1,000은 검증점 |
| `*_B0010000.*` | 건물 (`주기`에 `인문대학1동` 같은 이름) | 건물 윤곽 |

- 1:5,000 (`N3*`, 도엽번호 8자리): 37612018, 37612019, 37612028, 37612029 — DEM과 건물 윤곽
- 1:1,000 (`N1*`, 도엽번호 9자리): 22장 — 표고점만 DEM 검증에 쓴다
- 2025년판(폴더 이름의 `2025`), 좌표계 EPSG:5186(.prj), 속성 인코딩 CP949(EUC-KR)
- 출처: 국토교통부 국토지리정보원, 수치지형도 Ver2.0

다시 받으려면: 국토정보플랫폼 → 공간정보받기 → 영역(사각형)으로 캠퍼스를 고르고 "수치지형도Ver2.0(SHP,NGI파일)"을
받아 `data/topo/<압축 파일 이름>/` 에 푼다. 도엽마다 파일 이름이 같으므로 한 폴더에 섞어 풀면 안 된다.
