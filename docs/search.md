# 과목 검색 (web/js/search.js)

검색창에 친 말로 과목을 찾아 맞는 정도대로 줄 세우고, 맞은 글자 위치(강조)를 돌려준다.
규칙은 백엔드 세션이 정하고(`web/js/search.js`), 화면(`web/js/app.js`)은 결과를 그리고 강조만 한다.
SNUTT(서울대 시간표 앱, wafflestudio)의 강의 검색 규칙을 따르고, 초성 섞기·치는 중인 글자·한영 자판·줄 세우기를 더했다.

## 무엇으로 찾나

| 친 말 | 찾는 것 | 예 |
|---|---|---|
| 띄어쓰기로 나눈 낱말 | 낱말을 **모두** 만족하는 과목(그리고) | `글쓰기 나민애`, `컴공과 자료구조` |
| 줄임말(한글 두 글자 이상) | 과목명에서 글자를 건너뛰며 차례대로 | `대글` → 대학 글쓰기, `컴개실` → 컴퓨터의 개념 및 실습, `선대` → 선형대수학, `자구` → 자료구조, `공수1` → 공학수학 1 |
| 초성·초성과 글자 섞기 | 홑자음은 그 자리 글자의 첫소리 | `ㅈㄹㄱㅈ`, `ㄷㅎ글쓰기`, `대ㄱ쓰기`, `ㅋㄱㅅ` |
| 치는 중인 마지막 글자 | 낱자 앞부분, 받침을 다음 글자 첫소리로 | `그` → 글, `대하` → 대학, `글쓱` → 글쓰기 |
| 영문 자판으로 친 한글 | 두벌식으로 바꿔서도 찾는다 | `eogkr rmfTmrl` → 대학 글쓰기, `dkfrhflwma` → 알고리즘 |
| 학과 줄임 | 학과 이름 낱말 머리부터 건너뛰며. `과`·`부` 로 끝나면 그 글자는 뗀다 | `컴공`·`컴공과` → 컴퓨터공학부, `국문과` → 국어국문학과, `인지과` → 협동과정 인지과학전공 |
| 교수 | 이름 일부, 이름 전체는 초성도 | `나민애`, `ㄴㅁㅇ` |
| 교과목번호 | 친 그대로(대소문자 무시), 여섯 글자 이상이면 마침표 없이도 | `M1522.000900`, `m1522000900`, `1522`, `4190` |
| 분반 번호(숫자 세 자리) | 그 분반이 있는 과목 | `M1522.000900 001` (수강편람에서 붙여 넣기) |
| 특별 낱말 | 과목 정보로 거른다(SNUTT 가 받는 말에 `3학점` 을 더한 것. 아래 '줄 세우기'·'참고: SNUTT') | `전공`(전선·전필) `교양` `전선` `전필` `교직` `일선` `공통` `학부`·`학사` `대학원`·`석박` `석사` `박사` `3학점` `301동` `43-1동` `301-118`(강의실) `43-1` |
| 별칭(건너뛰기로 안 되는 줄임) | `ALIAS` 표 | `일물` → 물리학, `일화` → 화학, `일생` → 생물학 |

- 띄어쓰기·대소문자·가운뎃점·괄호 같은 문장부호, 전각 글자는 무시한다. 로마 숫자는 숫자로(`Ⅱ` = 2). 과목명 맨 앞 꼬리표 `(공유)` 는 줄임말 머리로 치지 않는다.
- `학` 으로 끝나는 낱말(`수학`·`경제학`)은 학과로 찾지 않는다(그 학과 과목이 다 딸려 나와서, SNUTT 와 같다). 학과는 이름 안쪽만 맞는 것(`대학` → 약학대학)도 찾지 않는다.
- 학과·교수는 두 글자부터. 낱말이 여럿이면 한 글자도 이름·학과의 앞부분으로 본다(`글쓰기 나` 를 치는 동안 나민애 교수 과목이 사라졌다 다시 나오지 않게).
- 검색창 값의 끝이 띄어쓰기면 마지막 낱말도 다 친 것으로 본다(치는 중인 글자 규칙을 쓰지 않는다).
- 강의실 번호는 치는 동안 앞부분만 맞아도 된다(`301-1` → 301-118 …).

## 줄 세우기

낱말마다 가장 잘 맞은 칸의 점수(작을수록 앞). 낱말이 여럿이면 평균, 띄어 쓴 검색어 전체가 과목명에 이어져 있으면(`대학 글쓰기`) 그 점수 하나.

| 점수 | 맞은 곳 |
|---|---|
| 0 | 과목명 처음(`(공유)` 다음)부터 이어져 |
| 0.5 | 교과목번호 전체 |
| 1 | 과목명 낱말 머리부터 이어져 |
| 1.5 | 교수 이름 전체(초성도) |
| 2 | 과목명 안에 이어져 |
| 3 | 낱말 머리글자 줄임(`대글` → **대**학 **글**쓰기). 과목명 처음에서 시작하지 않으면 3.2 |
| 3.2 | 과목명 처음부터 건너뛴 줄임(`자구` → **자**료**구**조) |
| 3.4 | 학과(낱말 머리부터) |
| 4 | 그 밖에 건너뛴 글자 |
| 4.5 | 분반 번호 |
| 5 | 교과목번호 일부(마디 처음. 마디 안이면 5.5) |
| 7 | 교수 이름 일부(앞부분 6.8) |
| 8 | 특별 낱말 |

- 치는 중인 글자로 맞으면 뒤로: 과목명 처음 1.5, 낱말 머리 2.5, 안 4.5.
- 줄임은 건너뛴 횟수(×0.1)와 건너뛴 글자 수(×0.1, 1까지)만큼 뒤로: `수연` → 수학연습(3.4)이 수의유전체의학 연구(3.7)보다 앞.
- **줄임말 판정**: 과목명 안에만 이어져 맞은 것(2)은, 그 낱말이 결과의 어느 과목명에서도 낱말 머리로 이어져 맞지 않으면 줄임말로 보고 3.8 로 내린다.
  `수연` 은 화학특**수연**구(안)보다 **수**학**연**습(줄임)이 앞. `구조` 는 구조동역학(처음)이 있으니 자료**구조**(안)가 구강조직학(줄임)보다 앞 그대로.
- **특별 낱말이 과목명에도 있을 때**(`교양` → **교양**연주, 현대독문학연습 (**교양**소설)). 과목명의 낱말 머리에 그 말이 있으면 과목 정보로 걸러지지 않아도 맞는다.
  안쪽에만 있는 것(유**전공**학의 `전공`)은 치지 않는다.
  - 그 낱말만 쳤으면 과목명에 그 말이 있는 과목이 앞(0·1), 걸러진 과목(8)이 뒤.
  - 다른 낱말과 함께 쳤으면 거르는 말로 먼저 본다: `교양 3학점` 은 교양이면서 3학점인 과목(8)이 가나다순으로 나오고,
    과목명에만 `교양` 이 있는 과목(전선)은 맨 뒤(8.2)다. 띄어 쓴 말 전체가 과목명에 이어져 있으면(`교양 소설` → 교양소설) 여전히 그것이 가장 앞이다.
- 별칭은 +0.2, 영문 자판을 바꿔 맞은 것은 +0.5.
- 같으면 앞에서 맞은 것, 짧은 과목명, 가나다(코드) 순.

## 화면 연결 (app.js)

```js
import { indexCourses, searchCourses, splitMarks, normKey } from "./search.js";

const index = indexCourses(state.courses);          // 과목 자료를 읽은 뒤(학기를 바꾼 뒤) 한 번
const { hits } = searchCourses(index, $("q").value); // 검색창 값을 그대로(끝의 띄어쓰기도)
// hits: [{ c, score, kind, marks }] 좋은 순
//   kind  가장 잘 맞은 칸: "name" "initials" "fuzzy" "id" "dept" "prof" "special"
//   marks { name?, id?, dept?: [[시작, 끝), ...] 원래 글자 위치, prof?: { name, ranges } } — 그릴 때 처음 읽으면 만든다
splitMarks(c.name, hit.marks.name);                 // → [{ text, mark }]: mark 인 조각을 <b> 로
normKey("대학  글쓰기");                              // → "대학글쓰기" (최근 검색어에서 같은 말을 하나로)
```

- 과목명 강조는 `marks.name`(건너뛴 줄임은 여러 조각). 메타 줄은 `marks.prof` 가 있으면 교수 이름, 아니면 `marks.id` 가 있으면 교과목번호, 아니면 학과(`marks.dept` 로 강조)를 보이면 맞은 까닭이 보인다.
- 한 글자 칠 때마다 다시 찾아도 된다(아래 빠르기). 배포 때 `export_web.py --stamp` 가 app.js 의 `"./search.js"` 주소에도 판(?v=)을 붙이고, 서비스 워커(sw.js)는 `js/search.js` 를 미리 저장한다.

## 빠르기

실제 2026-2 자료(과목 4,095개), 클라우드 작업 공간의 node:

- 색인 만들기 약 55 ms(한 번).
- 한 글자 칠 때마다 검색: 평균 약 1 ms, 가장 느린 것(`ㄱ` 처럼 결과가 3,000개 넘는 한 글자) 약 5 ms.
  폰은 몇 배 느려도 한 프레임 안팎이다. 초성·숫자 비트로 먼저 거르고, 줄임 맞추기(동적 계획법)는 글자가 차례대로 다 있을 때만 한다.

## 고칠 때

- 별칭: `ALIAS`. 점수: `S`, `LATE`, `fuzzyScore`. 특별 낱말: `special`.
- 테스트: `tests/test_search.py` — 작은 가짜 과목 목록으로 줄 세우기, 실제 자료(`data/lectures.json`)로 빠르기·그리고·강조 범위. `tests/search_runner.mjs` 를 node 로 부른다(node 가 없으면 건너뛴다).

## 참고: SNUTT

- wafflestudio/snutt(예전 이름 snutt-timetable) `core/src/main/kotlin/lectures/repository/LectureCustomRepository.kt` (`makeSearchCriteriaFromQuery`)
- wafflestudio/snutt-v2 `core/.../common/search/SearchKeywordClassifier.kt`
- SNUTT 는 낱말마다 `글.*자.*사.*이` 꼴 정규식으로 과목명을 찾고(줄임), 학과는 `^` 부터, 교수는 이름 전체가 같을 때만. 점수가 없어 사용자가 고른 정렬 순서로 나온다.
  초성·치는 중인 글자·영문 자판·줄 세우기는 없다.
- 특별 낱말(2026-10 main 기준): `전공`·`학부`·`학사`·`대학원`·`석박`·`체육`·`영강`·`군휴학`·`권장과목`·건물(`301동`)·강의실(`301-118`)은 **거르기만** 한다(과목명은 안 본다).
  `교양`·`전선`·`전필`·`석사`·`박사` 같은 그 밖의 한글 낱말은 '과목명에 그 글자가 차례로 있거나 / 구분·학년 구분이 그 말이거나 / 학과 앞부분이거나 / 교수 이름이거나' 가운데 하나면 맞는다.
  그래서 `교양` 은 교양 과목과 과목명에 교…양 이 있는 과목이 순서 없이 섞여 나온다. `3학점` 은 낱말로는 못 찾고 따로 고르는 조건이다.
  여기서는 같은 말을 다 받되(더 넓게), 낱말이 여럿일 때는 거르기를 먼저 본다(위 '줄 세우기').
