# 수치지형도 (국토지리정보원)

`scripts/dem_from_contours.py`(DEM·건물 윤곽), `scripts/basemap.py`(바탕 지도), `scripts/entrance_links.py`(출입구 접속선)가 읽는 원자료다.

## 저장소에는 없다 (2026-10-05)

원본 파일은 저장소에 올리지 않고 PC 의 `data/topo/` 에만 둔다(`.gitignore`).

- 수치지형도는 공공누리 제1유형(출처 표시)이라 저작권으로는 다시 올려도 되지만, 「공간정보의 구축 및 관리 등에 관한 법률」 제16조·제21조가
  측량성과 중 지도등을 국토교통부장관 허가 없이 국외로 반출하지 못하게 한다. 시행령 제16조의 예외에 1:5,000·1:1,000 수치지형도는 없다.
  이 저장소(GitHub)의 서버는 해외에 있어서, 2026-10-05 에 원본을 내렸다(그 전 커밋에는 남아 있다).
- 이 자료로 만든 것(`data/basemap.json`, 고도 표, `web/model/`)을 어떻게 할지는 국토지리정보원에 물어 정한다(같은 법 제15조 간행심사 포함).
- 테스트는 가짜 도엽을 만들어 쓰므로 이 폴더가 없어도 돈다. 위 스크립트 셋은 이 폴더가 있는 PC 에서만 돈다.

## 받는 법

국토정보플랫폼(https://map.ngii.go.kr) → 공간정보받기 → 영역(사각형)으로 캠퍼스를 고르고 "수치지형도Ver2.0(SHP,NGI파일)"을 받아
`data/topo/<압축 파일 이름>/` 에 푼다. 도엽마다 파일 이름이 같으므로 한 폴더에 섞어 풀면 안 된다.

- 1:5,000 (`N3*`, 도엽번호 8자리): 37612018, 37612019, 37612028, 37612029 — DEM, 건물 윤곽, 바탕 지도(범위 = 이 네 장)
- 1:1,000 (`N1*`, 도엽번호 9자리): 22장 — 표고점은 DEM 검증에, 건물(`N1A_B0010000`, 무벽건물 = 캐노피·연결통로는 지나갈 수 있다)과
  아래 장애물 선·계단은 출입구 접속선(`scripts/entrance_links.py`)에 쓴다
- 2025년판(폴더 이름의 `2025`), 좌표계 EPSG:5186(.prj), 속성 인코딩 CP949(EUC-KR)
- 출처: 국토교통부 국토지리정보원, 수치지형도 Ver2.0

## 스크립트가 읽는 레이어

압축 파일에는 레이어가 60여 개 들어 있고, 스크립트는 아래 것만 읽는다.

| 파일 | 내용 | 쓰는 곳 |
| --- | --- | --- |
| `*_F0010000.*` | 등고선 (`등고수치`, 5 m 간격) | DEM |
| `*_F0020000.*` | 표고점 (`수치`) | DEM, 1:1,000은 검증점 |
| `*_B0010000.*` | 건물 (`주기`에 `인문대학1동` 같은 이름) | 건물 윤곽, 바탕 지도 |
| `N3A_A0010000.*` | 도로경계(면) | 바탕 지도 (1:5,000만) |
| `N3A_A0033320.*` | 인도(면) | 바탕 지도 (1:5,000만) |
| `N3A_E0010001.*`, `N3A_E0032111.*`, `N3A_E0052114.*` | 하천경계, 실폭하천, 호수·저수지 | 바탕 지도 (1:5,000만) |
| `N1L_B0020000.*` | 담장·철책·판자담(`구분`. 문주는 문 자리) | 출입구 접속선의 장애물 (1:1,000만) |
| `N1L_F0040000.*`, `N1L_F0030000.*` | 옹벽·석축(`종류`, `상하구분`, `높이`), 절토 | 〃 |
| `N1L_C0530000.*`, `N1L_C0050000.*`, `N1L_G0030000.*` | 가드펜스·가드레일, 제방, 기타구조물(`용도` 가 벼랑바위인 것만 장애물) | 〃 |
| `N1A_C0390000.*` | 계단(면) | 접속선이 지나가면 `kind: steps` (1:1,000만) |
