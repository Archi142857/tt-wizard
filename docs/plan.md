## 정한 것

- 문제 모델: GTSP 특수형 → 분반 선택(CSP). 하드 제약은 시간 겹침만, 이동 가능 여부는 지각 페널티
- 평가: 주간 총 이동시간 단일 기준으로 시작 (등교 일수·공강은 가중치 0, 확장 항목)
- 탐색: 백트래킹 + 분기 한정, 작으면 완전탐색, 커지면 SA
- 데이터 갱신: 12h 기본, 새 학기 감지 후 30일과 수강신청 기간은 6h (첫 화면 일정표 파싱)
- 이동시간: '캠퍼스 마법 지도' 데이터 1순위 → TMAP 보행자 API → 수동. 네이버 앱 20~30쌍은 보정 표본, 실측 3~5구간은 검증
- 지도 표시: OpenStreetMap 타일 + Leaflet
- 입력: 과목 검색 → 목록 추가. 그룹·택1 없음. 과목을 펼치면 분반별 체크박스
- 출력: 3분할, 결과만 표시(점수·퍼센트 없음), 모바일도 3분할, 세로 스크롤
