# 비교 실험 — 방법

분반을 어떻게 고르느냐에 따라 주간 이동시간이 얼마나 달라지는지, 프로그램이 고른 시간표가 무작위나 실제 선택보다
얼마나 나은지 잰다. `scripts/experiments.py` 가 돌리고, 결과(CSV·그림·요약)는 `results/experiments/` 에 쓴다.
수치는 `results/experiments/README.md` 에 있고 이 문서는 정의와 방법만 적는다.

```bash
python scripts/experiments.py                                   # 1·2·2b (가상 묶음 1,000개, 2분 남짓)
python scripts/experiments.py --real data/experiments/real_timetables.csv   # 3까지
python scripts/experiments.py --bundles 500 --seed 1 --no-history --no-stress
```

## 공통

- **편람.** 지금 학기는 `data/lectures.json`(웹 화면과 같은 자료), 지난 학기는 `data/raw/history/<학기>.xls`.
  학년·개설학과·수강신청인원·비고는 lectures.json 에 없어서 같은 학기 엑셀에서 읽는다.
- **대상 분반.** 학부(이수과정 학사)·설강·수업시간이 있는 분반. 조합 실험(2·3)에서는 모든 수업의 건물이 정해진
  분반만 후보로 둔다. 강의실 미정 수업은 이동을 만들지 않아서(앱 규칙) 넣어 두면 1위가 그쪽으로 쏠린다.
- **이동시간.** 웹 화면과 같은 행렬(`export_web.export_campus`). 캠퍼스 마법 지도 도로 그래프(점검·보강한 것) 위에서 찾은 우리 경로의
  시간이다: 경사 반영 = Tobler 보행 함수(30 m 창. 계단 엣지는 계단 속도식)로 잰, 방향마다 가장 빠른 경로의 시간. 평지 = 최단거리 경로의 길이 ÷ 1.1 m/s
  (경사가 없다면 걸을 길). 추정값이고 실측이 아니다(`docs/travel_time_method.md`).
  2026-10-02 까지는 마법 지도 건물쌍 표 × 경사 계수였다. 기준을 바꿔도 결론은 같았다(무작위 대비 절약 주 14.6분 → 14.5분).
  2026-10-03(update44)에 경사 반영 시간을 최단거리 경로의 시간에서 가장 빠른 경로의 시간으로 바꾸고(주 15.1분 → 15.0분),
  계단에 계단 속도식을 넣었을 때도 같았다(15.0분 → 14.8분).
- **하루 경로와 비용.** 집 → 그날 수업들 → 집. 비용 = 이동시간 + 2 × 지각(분). 앱과 같다. '1위'는 앱이 첫 번째로
  보여 주는 조합이다. 집은 기숙사(919A동: 웹 화면의 '기숙사'가 처음 고르는 동. 2026-10-03 까지는 919 한 점)와 정문(GATE) 두 경우를 따로 잰다.
- **주간 → 학기.** 한 학기 = 15주로 곱한다.

## 1. 분반–건물 분산

- 분반이 둘 이상인 과목에서 분반들이 쓰는 건물이 둘 이상이면 '여러 건물에 흩어진 과목'.
- 비율의 분모는 건물을 하나라도 아는 과목이다(`ratio`). `docs/stats_2026-2.md` 의 48.4 %는 강의실 미정 과목까지
  분모에 넣은 값이고 `spread_summary.csv` 의 `ratio_all` 과 같다.
- 수강인원 가중 비율 = 흩어진 과목의 수강신청인원 합 ÷ 전체 수강신청인원 합.
- 가장 먼 두 건물 = 분반 건물 쌍의 경사 반영 시간(두 방향 평균) 가운데 최댓값. 흩어졌어도 이웃 건물이면 작다.
- 학기별 비율은 2021-1부터. 지난 학기 편람은 학기가 끝난 뒤 받은 것이라 강의실이 거의 다 찼으므로,
  학기끼리는 건물을 아는 과목 기준(`ratio_located`)으로 견준다.

## 2. 가상 묶음: 프로그램 vs 무작위

**묶음 만들기** (`make_bundles`, 시드 고정)

1. 코호트(개설대학, 개설학과, 학년 1~4)를 고르게 하나 뽑는다. 전공(전필·전선) 과목이 2개 이상인 코호트만.
2. 과목 수는 5 또는 6. 전공은 1학년 2개, 2학년 이상 4개(코호트에 그만큼 없으면 있는 만큼), 나머지는 교양.
3. 교양은 그 학생이 들을 수 있는 분반의 수강신청인원 합에 비례해 뽑는다. 많이 듣는 대학 글쓰기·영어·수학·과학 실험이
   자주 나온다.
4. 과목마다 그 학생이 고를 수 있는 분반만 남기고, 시간이 겹치지 않는 조합이 하나도 없으면 다시 뽑는다.

**수강 제한** (`scripts/restrictions.py`, 실제 문구로 `tests/test_restrictions.py` 에서 확인). 비고의 ® 문구를
단과대·학과 이름으로 읽는다. 학과 이름은 그 학기 수강편람의 개설학과에서 모으고, 줄임말(화생공, 재료공, 자전 …)은 따로 적어 둔다.

- 외국인 유학생반·글로벌 인재반·외국인 학생(영어강좌)처럼 특정 학생만 받는 분반은 뺀다. ®가 없으면 누구나 들을 수 있다.
- 안내 괄호(정원 외 신청·주소)를 지우고 '/' 로 나눈 뒤(괄호 안과 날짜 8/4 의 '/' 는 두고), 이름·'모든 학생'·'타과생'·
  '주전공'·'N학년만' 이 처음 나오는 조각으로 정한다. 본 수강신청 기간의 배정이다(변경기간 안내는 보지 않는다).
- 이름 뒤에 처음 오는 말로 뜻을 정한다: '제외' → 빼기, '불허·불가·금지·제한' → 막기, 그 밖 → 받기.
  '(… 외)'·'(… 제외)' 괄호 안은 빼기, 'X 외 수강 불허' 는 X 만 받기.
- 단과대 바로 뒤에 붙은 학과가 앞선다('공대_재료공학부' 는 재료공학부만, '자연대 수리과학부, 통계학과' 는 두 학과만).
  막힌 단과대 안에서 따로 받는 학과는 예외다('음대생 수강 불허(국악과만 수강 가능)').
- '타과생 수강금지' 는 개설학과 학생만, '타과생은 5~6일차에 가능' 은 누구나. 이름 없는 '주전공생 대상' 은 개설학과 학생만.
- 'N학년만'·'N학년 이상' 은 묶음의 학년(코호트 학년)으로 따진다. 문구에 '전 학년·전체 학년' 으로 넓히는 말이 있으면
  따지지 않는다.
- 정할 조각이 없는 제한(® 만 있는 36개 분반, '6학기 이상 이수자' 등)은 못 듣는 것으로 본다.

**무작위.** 시간이 겹치지 않는 조합 가운데 균등하게 하나를 고르는 학생(위치를 전혀 안 보고 고르는 경우의 모형).
분반을 과목마다 균등하게 뽑고 겹치면 버리는 것과 같다. 조합이 2만 개 이하면 전부로, 넘으면 4,000개 균등 표본으로
분포를 잰다(5만 개 이하는 목록에서 뽑고, 그보다 많으면 버리기 표집).

요약(`summary.csv`)의 평균 절약에는 95% 구간(평균 ± 1.96 × 표준오차)을 같이 적는다. 묶음을 새로 뽑으면(시드, 규칙,
편람이 바뀌면) 평균이 그 정도 흔들린다.

**지표**

| 열 | 뜻 |
| --- | --- |
| `opt_travel`, `opt_late`, `opt_cost` | 1위의 주간 이동시간·지각·비용(분) |
| `random_travel_mean`, `random_travel_median`, `random_travel_max` | 무작위 조합의 주간 이동시간 평균·중앙값·최댓값(최댓값은 전부 셀 때만) |
| `random_late_share`, `random_late_mean` | 무작위 조합에 지각 구간이 있을 확률, 지각 평균 |
| `has_choice` | 분반에 따라 비용이 달라지는 묶음인지(시간이 안 겹치는 조합이 여럿이어도 비용이 모두 같으면 아니다) |
| `saving`, `saving_ratio` | 무작위 평균 − 1위 이동시간, 그 비율. 1위는 지각까지 넣은 비용을 줄이므로 지각이 있는 무작위보다 이동이 길 수도 있다(음수) |
| `cost_saving` | 비용 기준 절약. 늘 0 이상 |
| `lower_bound`, `opt_over_bound` | TSP 하한(`bound.py`)과 1위 ÷ 하한 |
| `slope_loss`, `flat_choice_optimal` | 평지 행렬로 고른 1위를 경사 반영 비용으로 쟀을 때 경사 반영 1위보다 더 드는 비용, 그게 0(같은 답)인지 |
| `opt_travel_flat`, `slope_extra` | 1위를 평지로 잰 이동시간, 경사 반영이 늘린 비율 |
| `n_combinations`, `n_combinations_grouped`, `n_feasible` | 분반 수의 곱, 같은 시간·건물 분반을 묶은 뒤의 곱(앱이 실제로 뒤지는 공간), 시간이 안 겹치는 조합 수 |
| `py_ms`, `js_ms`, `js_cost_matches` | 파이썬·웹 엔진(node) 탐색 시간(상위 5개, 앱과 같게 분반을 묶은 뒤), 두 엔진의 1위 비용이 같은지 |

**TSP 하한을 읽는 법.** 하한은 과목마다 한 번씩만 들르는 가장 짧은 순회라서, 요일마다 집을 오가고 같은 건물에
여러 번 가는 실제 시간표보다 한참 짧다. 1위 ÷ 하한이 크게 나오는 것은 하한이 느슨하다는 뜻이다. 탐색의 가지치기는
주로 부분 조합의 비용(삼각부등식을 맞춘 행렬로 잰 값)이 맡는다.

## 2b. 부하 시험

수강인원이 가장 많은 교양 k개(4~8)를 모든 분반 그대로 넣고 탐색 시간을 잰다. 웹 화면은 수강 제한을 모르므로
분반을 끄지 않으면 이 상태로 찾는다(이공계 1학년이 기초 과목을 한꺼번에 담은 경우). SA 같은 휴리스틱이 필요한지
판단하는 근거다. 시간은 실험을 돌린 컴퓨터의 node 기준이라 폰에서는 몇 배 걸릴 수 있다.

## 3. 실제 시간표

입력 CSV (UTF-8, 한 줄에 과목 하나). 개인 자료라 `data/experiments/` 에 두고 git 에 올리지 않는다(`.gitignore`).
이름은 넣지 않고 사람은 A, B, …로 구분한다.

```csv
person,semester,college,department,course,section
A,2026-2,농업생명과학대학,식품동물생명공학부,M1702.001100,001
A,2026-2,농업생명과학대학,식품동물생명공학부,대학 글쓰기 1,012
```

- `semester` 가 비면 지금 학기. `course` 는 교과목번호나 교과목명(부제 빼고 정확히), `section` 은 강좌번호.
- `college`·`department`(수강편람의 개설대학·개설학과 표기)는 수강 제한을 읽는 데 쓴다. 학년 제한을 따지려면 `year` 열(1~4)을
  더 넣는다. 실제로 고른 분반은 제한 해석과 상관없이 후보에 넣는다.
- 지표: 실제 선택의 이동시간·지각, 1위, 무작위 평균, 실제 선택이 가능한 조합 중 어디에 드는지
  (`real_percentile`, 비용 기준, 0 = 가장 좋은 쪽, 1 = 가장 나쁜 쪽).
- `note`: 강의실 미정 수업(이동 0으로 계산), 시간 겹침(입력 오류일 가능성), 행렬에 없는 건물(좌표로 추정).
- `real.csv` 에는 과목·분반이 들어가므로 올리지 않는다. 요약(`README.md`)과 그림(`fig7_real`)만 올린다.

## 한계

- 이동시간은 추정값이다. 오르막 실측으로 검증하기 전이다.
- 가상 묶음은 실제 수강 조합이 아니다. 교양을 단과대와 상관없이 수강인원 비례로 뽑아서 이공계 기초 교양이 비이공계
  묶음에 들어가기도 한다. 실제 시간표 비교로 보완한다.
- 수강 제한 해석은 규칙이라 틀릴 수 있고, 틀리면 선택지가 늘 수도 줄 수도 있다. 본 수강신청 배정만 보므로
  변경기간에 남는 자리로 듣는 경우는 빠진다.
- 정원·수강신청 경쟁(원하는 분반이 마감되는 것)은 반영하지 않았다.
- 무작위는 위치를 전혀 보지 않는 학생의 모형이다. 실제 학생은 시간대·교수도 보고 고른다.
