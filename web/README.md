# web/

TT Wizard 화면. 정적 사이트라 서버 없이 돈다: `data/*.json` 을 읽고, 탐색은 브라우저에서 `js/engine.js`
(ttwizard 의 이동시간 행렬·평가·탐색을 옮긴 것)가 한다. 주소: https://archi142857.github.io/tt-wizard/ (Pages 를 켠 뒤)

- 디자인: TT Wizard 디자인 규칙 v3(공유 폴더 `디자인_시스템.md`, `design\v3\TT Wizard 디자인 규칙.md`). 색·간격·모서리·글자·모션 토큰은
  `style.css` 맨 위 `:root` 에 있고 이름은 디자인 시스템 `tokens.json` 과 같다. 컴포넌트는 디자인 시스템 `components/bundle.css` 를 옮긴 것이라
  클래스 이름도 같다(`.topbar`, `.course`, `dialog.sheet`, `.snackbar` …). 굵기는 400·500·700, 글자는 12px 이상, 글자 크기는 `rem`(지도 그림 안 글자만 px:
  핀 번호, 구간 라벨, 건물 번호 12px 700·이름 12px 500, 등고선 높이 12px 500).
  단, 연도·학기 선택칸, 시간표 칸, 지도 번호표, 후보 카드는 사용자 요청(2026-10-01)으로 v2 모양을 v3 토큰으로 칠한 것이고,
  입력 화면 로고는 사용자 요청으로 워드마크만(`icons/wordmark.svg`, 디자인 세션 원본, 높이 `logo-topbar` 36px) 쓴다
- 다크 테마: 기기 설정(`prefers-color-scheme`)을 따른다. 다크 값은 `style.css` 의 `@media (prefers-color-scheme: dark)` 두 곳(토큰, 다크 전용 규칙)에
  있다. 로고는 `<picture>` 로 `wordmark-dark.svg`, 바탕 지도는 다크 지도 색(`--map-*`)으로 따로 그린다. `theme-color` 는 라이트 `#EEF0FF`·다크 `#16171B`
- 이벤트 테마(디자인 규칙 '이벤트 테마', 10/3): 정해 둔 기간에 저절로 켜지는 한 벌짜리 테마. 첫 테마는 크리스마스(`xmas`, 해마다 12월 1일~25일, 기기 날짜).
  색과 맨 뒤 바탕 무늬만 바꾸고 크기·간격·문구·동작은 그대로다. 기본 테마 화면은 라이트·다크 모두 넣기 전과 화소 단위로 같다
  - 켜기: `<html data-theme="xmas">`. `index.html` 머리의 작은 스크립트가 그리기 전에 걸고(바탕이 번쩍이지 않게, `theme-color` 도 그 테마의 `bg`
    `#103924` 로), `app.js` 의 `THEMES`·`seasonTheme`·`applyTheme` 이 같은 판단을 한다. **둘을 같이 고친다**(기간, 값, 저장 이름).
    앱을 켜 둔 채 기간이 시작되거나 끝나면 보는 동안은 그대로 두고, 다른 데 갔다가 돌아올 때(`visibilitychange`) 날짜를 다시 본다
  - 묻기: 켜진 뒤 처음 들어왔을 때 한 번 묻는 시트(`#theme-ask`, `.sheet.ask`) `기본 테마로 돌아갈까요?` [닫기] [돌아가기]. 처음 초점은 제목(테두리 없음).
    `돌아가기`만 끄고 닫기·바깥·Esc·뒤로 가기·끌어내리기는 그대로 둔다. 시간표를 만든 적 없으면(`ttw.made`) 묻지 않고, 0.4초 사이에 다른 화면이나
    시트를 열었으면 끼어들지 않고 다음에 켤 때 묻는다. 테마가 켜진 채 처음 시간표를 만든 사람도 그 해에는 묻지 않는다(10/3 밤 디자인: 기본 테마를
    써 본 적이 없어 돌아갈 곳이 없다. `showResult` 가 그 순간 `ttw.themeAsked` 에 그 해 것을 적는다. `테마` 행으로는 바꿀 수 있고 다음 해에는 묻는다)
  - 정보 화면 `테마` 행: 기간에만 목록 맨 위. `기본`·`크리스마스` 선택칸, 고르면 바로 바뀌고 초점은 그대로, 알리지 않는다. 보이는 값(`.info-pick`, 14px) 위에
    투명한 `select` 를 덮었다(과목 시트의 강의실 값과 같은 방식): 보이는 `select` 를 16px 보다 작게 두면 iOS 가 누를 때 화면을 확대한다
  - 저장: `ttw.themeOff`(끈 테마)·`ttw.themeAsked`(물어본 테마), 값은 해마다 다른 이름 `xmas-2026` 이라 다음 해에는 다시 켜지고 다시 묻는다
  - 시험: 주소에 `?theme=xmas` 를 붙이면 기간 밖에서도 켜진다(화면을 옮겨도 주소에 남는다). 이때 고른 것은 `xmas-test` 로 따로 기억해 실제 12월에 남지 않는다.
    스토어 앱은 주소를 못 바꾸니 기기 날짜를 옮겨 본다
  - 색: `style.css` 의 `html[data-theme="xmas"]` 블록(디자인 시스템 `tokens.json` 의 `xmas` 값). 테마는 한 벌이라 기기가 다크여도 같은 모습이고, 기본 테마의 다크 값과
    다크 전용 규칙은 테마가 꺼져 있을 때만 건다(`:root:not([data-theme])`, `html:not([data-theme])`). 바탕 위에 놓이는 것은 따로 나눈 토큰을 쓴다:
    `on-bg-heading`·`on-bg-text`·`on-bg-text2`·`on-bg-text3`·`on-bg-link`·`on-bg-danger`, `bg-hover`, 그리고 `inset`(카드 안 파인 면), `accent-line`(고른 후보 테두리),
    `cta`·`on-cta`(주요 버튼, 고른 요일 탭), `on-home`. 기본 테마에서는 모두 원래 토큰을 가리킨다. **바탕 위에 새 글자·아이콘을 놓을 때는 `on-bg-*` 를 쓴다**
    (`text`·`heading` 을 쓰면 짙은 바탕에서 안 보인다). 선택칸 화살표는 그림이라 테마 블록에서 따로 바꾼다
  - 무늬: 화면에 붙인 맨 뒤 층 `body::before` 하나(`position: fixed`, `--bg-pattern`). 상단 바와 하단 띠는 같은 무늬를 화면 기준으로 다시 그려(`.topbar::before`,
    `.bottom-bar::before`) 밑으로 들어온 카드를 가리면서 무늬가 이어진다. 넓은 화면의 오른쪽 칸 하단 바는 `clip-path` 로 그 자리만 보이게 자른다. 전체 화면 지도의
    지도 밖도 무늬이고 번호표는 `card` 면, 색 풀이 줄은 무늬 없는 `bg` 판 위. 대비를 높인 기기(`prefers-contrast: more`)와 강제 색에서는 무늬를 끄고,
    강제 색에서는 워드마크·선택칸 화살표도 기본 그대로 둔다
  - 워드마크는 흰 단색 `icons/wordmark-white.svg`. 화면 스크롤 막대가 자리를 차지하는 브라우저(윈도우)에서는 길을 바탕색으로 칠한다(`scrollbar-color`, 카드 안은 그대로)
  - 스토어 앱: 화면이 상태 바 밑까지 그려져서 `Capacitor.Plugins.SystemBars.setStyle` 로 상태 바 글자를 밝게(`DARK`) 바꾸고 테마를 끄면 `DEFAULT` 로 돌린다
    (없으면 건너뛴다). 시작 화면·앱 아이콘·매니페스트 색은 기본 테마 그대로다
  - 새 테마: `THEMES` 한 줄(값, 이름, 시작·끝 `MM-DD`, `bg`, 시스템 바 글자), 머리 스크립트의 기간·값, `style.css` 에 `html[data-theme="…"]` 토큰 블록과 무늬,
    바탕이 짙으면 흰 워드마크 규칙. 기간은 한 해 안에 두고(해를 넘기면 날짜 비교와 저장 이름을 고쳐야 한다) 서로 겹치지 않게 한다
- 화면은 입력 · 결과 · 정보 셋이고 전체 화면 지도, 자료 출처·오픈소스 라이선스가 그 위에 뜬다. 화면만 방문 기록(`pushState`)을 남겨
  시스템 뒤로 가기와 상단 바 뒤로가 한 단계씩 닫는다. 시트(과목, 이동시간 계산 방법, 홈 화면에 추가)는 `<dialog>` 라 Esc·Android 뒤로 가기로 닫힌다.
  새로 켜면 늘 입력 화면에서 시작한다

  → 검색(찾는 규칙과 줄 세우기는 `js/search.js`, 백엔드 몫, 레포 `docs/search.md`: 띄어 쓴 낱말을 모두 만족, 줄임말 `대글`·`선대`, 초성과 글자 섞기

  화면은 맞은 글자를 굵게 하고(줄임말은 글자마다), 메타 줄 첫 칸은 교수·교과목번호로 맞으면 그것, 아니면 학과. 검색창 값은 끝의 띄어쓰기까지 그대로 넘긴다.

  담기·빼기이고, 담은 과목의 행은 어두운 바탕에 `✓ 담음`. 검색 전에는 `최근 검색어` 칩: 담기로 이어졌거나 Enter 로 낸(결과가 있는) 검색어
  10개까지, 띄어쓰기·대소문자·문장부호만 다른 말은 하나로(`normKey`), 누르면 그 말로 검색, ×로 하나·`모두 지우기`로 전부. 폰은 빈 검색창에 초점이 있을 때만
  띄우고 초점이 검색창·카드 밖으로 나가면 0.25초 뒤 내린다(누른 자리가 밀리지 않게)) → 담은 과목(제목 옆 `총 18학점`, 행을 누르면 과목 시트, ×로 빼면 되돌리기 스낵바, 아래에

- 넓은 화면(폭 680px~, 태블릿·펼친 폴더블·PC·가로로 눕힌 폰): 입력 화면을 두 칸으로(`.input-left` 학기·검색 | `.input-right` 담은 과목·조건).

  오른쪽은 폭 고정 `--width-pane` 360px(784px 아래에서는 두 칸이 반씩, 펼친 폴더블은 접힌 자리가 두 칸 사이 틈에 온다).

  양옆 12px 를 비운다. 그보다 좁으면 한 칸 + 하단 고정 바(되돌리기 스낵바는 두 칸에서 `placeSnackbar` 가 `시간표 만들기` 바로 위, 같은 폭에 둔다).

## 배포

`.github/workflows/pages.yml` 이 main 에 푸시할 때와 수강편람 자동 갱신이 끝날 때마다 자료를 만들어 올린다.
처음 한 번 레포 Settings → Pages → Source 를 "GitHub Actions" 로 바꾼다.

배포할 때는 `export_web.py --stamp` 로 `index.html`·`js/app.js` 가 부르는 `style.css`·`app.js`·`engine.js` 주소에
판(`?v=<내용 해시>`)을 붙인다. GitHub Pages 는 파일을 10분 동안 서버에 다시 묻지 않고 쓰게 해서, 판이 없으면 배포 직후
새로고침한 화면에 옛 스크립트가 붙는다(새 화면 + 옛 동작. 2026-09-29 학기 선택을 올렸을 때 선택 줄이 안 보였던 까닭).
레포의 파일에는 붙이지 않는다. 로컬에서 `--stamp` 를 쓰면 그 두 파일이 바뀌니 되돌린다.
