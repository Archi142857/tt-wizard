TT Wizard 화면. 정적 사이트라 서버 없이 돈다: `data/*.json` 을 읽고, 탐색은 브라우저에서 `js/engine.js`
(ttwizard 의 이동시간 행렬·평가·탐색을 옮긴 것)가 한다. 주소: https://archi142857.github.io/tt-wizard/ (Pages 를 켠 뒤)

  `style.css` 맨 위 `:root` 에 있고 이름은 디자인 시스템 `tokens.json` 과 같다. 컴포넌트는 디자인 시스템 `components/bundle.css` 를 옮긴 것이라

  핀 번호, 구간 라벨, 건물 번호 12px 700·이름 12px 500, 등고선 높이 12px 500).

- 화면은 입력 · 결과 · 정보 셋이고 전체 화면 지도, 자료 출처·오픈소스 라이선스가 그 위에 뜬다. 화면만 방문 기록(`pushState`)을 남겨
  시스템 뒤로 가기와 상단 바 뒤로가 한 단계씩 닫는다. 시트(과목, 이동시간 계산 방법, 홈 화면에 추가)는 `<dialog>` 라 Esc·Android 뒤로 가기로 닫힌다.
  새로 켜면 늘 입력 화면에서 시작한다

  화면은 맞은 글자를 굵게 하고(줄임말은 글자마다), 메타 줄 첫 칸은 교수·교과목번호로 맞으면 그것, 아니면 학과. 검색창 값은 끝의 띄어쓰기까지 그대로 넘긴다.
  폰은 8개씩 `더 보기`(넓은 화면은 아래 '넓은 화면'). 행 어디를 눌러도
  담기·빼기이고, 담은 과목의 행은 어두운 바탕에 `✓ 담음`. 검색 전에는 `최근 검색어` 칩: 담기로 이어졌거나 Enter 로 낸(결과가 있는) 검색어

  띄우고 초점이 검색창·카드 밖으로 나가면 0.25초 뒤 내린다(누른 자리가 밀리지 않게)) → 담은 과목(제목 옆 `총 18학점`, 행을 누르면 과목 시트, ×로 빼면 되돌리기 스낵바, 아래에
  교과구분 색 풀이) → 조건(출발·도착, 이동시간) → 하단 `시간표 만들기`(폰에서 가상 키보드가 떠 있는 동안만 숨긴다. 초점이 아니라
  보이는 높이로 판단해서, 키보드를 내리면 검색창에 초점이 남아도 다시 보인다)
- 출발·도착(10/2 디자인 '조건'): 세그먼트 `기숙사 | 정문 | 다른 건물`, 아래 선택칸 `#home-select` 한 자리를 같이 쓴다(`syncHomeSelect`).
  `기숙사`면 동(이름 `기숙사 동`, update40 자료 `campus.json` 의 `dorms` 가운데 이동시간 지점(`ids`)인 24개 동을 번호순으로 번호만
  `900동` … `946동`, 처음 `919동`. 919-A~D 는 없다), `다른 건물`이면 건물(이름 `건물`, `301동 제1공학관`), `정문`이면 숨긴다.
  세그먼트 라디오는 다시 그리지 않아 선택칸이 바뀌어도 초점이 고른 라디오에 남는다. 기숙사 동은 `건물` 목록과 과목 시트의 강의실
  목록에서 뺀다(`buildingOptions`. 전에 넣어 둔 값은 그대로 보인다). 마지막에 고른 기숙사 동과 다른 건물은 따로 기억해 세그먼트를
  오가도 그대로다(`ttw.home`, `ttw.homeDorm`, `ttw.homeOther`). 결과 화면 이름은 어느 동이든 `기숙사`(`placeLabel`: 번호표 `⌂ 기숙사`,
  `기숙사 가는 길`, 핀 이름, 읽는 글)이고 조건 줄만 동을 밝힌다(`출발·도착 기숙사 906동 · 경사 반영`). `dorms` 가 없는 옛 자료면
  예전처럼 기숙사 = 919동 하나이고 선택칸이 없다
- 넓은 화면(폭 680px~, 태블릿·펼친 폴더블·PC·가로로 눕힌 폰): 입력 화면을 두 칸으로(`.input-left` 학기·검색 | `.input-right` 담은 과목·조건).
  흔한 '주 칸 + 보조 칸' 배치(Android 지원 창 배치, Polaris·GOV.UK 2/3+1/3, Apple 인스펙터, Microsoft 보조 칸): 왼쪽은 늘어나는 칸,
  오른쪽은 폭 고정 `--width-pane` 360px(784px 아래에서는 두 칸이 반씩, 펼친 폴더블은 접힌 자리가 두 칸 사이 틈에 온다).
  두 칸은 내용만큼의 높이이고(10/2 디자인: 카드를 늘려 아래 끝을 맞추면 빈 카드가 커 보였다) 둘 다 sticky 라 짧은 쪽이 제자리에 남는다.
  `시간표 만들기`는 오른쪽 칸 맨 아래에 칸 폭으로, 오른쪽 칸이 화면보다 길면 화면 아래에 붙는다. 두 칸 조건에 높이를 넣지 않는다(앱은 화상
  키보드만큼 창 높이가 줄어 타자 중에 한 칸으로 바뀌어 버린다). 책처럼 펴 둔 폴더블(Viewport Segments 두 쪽)은 두 칸을 한 쪽씩, 접힌 자리
  양옆 12px 를 비운다. 그보다 좁으면 한 칸 + 하단 고정 바(되돌리기 스낵바는 두 칸에서 `placeSnackbar` 가 `시간표 만들기` 바로 위, 같은 폭에 둔다).
  - 결과 카드는 자료를 받은 뒤 늘 있고(불러오는 중에는 없다) 카드 안에서만 스크롤한다(10/2 사용자): 왼쪽 칸을 상단 바 아래 화면 높이로
    묶고 카드만 남은 높이 안에서 줄어든다(학기 줄·검색창은 줄지 않는다). 스크롤 막대는 두지 않는다(10/2 사용자). 화면이 25em(400px)보다
    낮으면(가로로 눕힌 폰에 화상 키보드) 예전처럼 페이지가 스크롤한다.
    목록(검색 결과, 과목 둘러보기)은 `더 보기` 없이 다 보인다(10/2 사용자): `feedList` 가 16개씩 그리고, 끝의 6개 행 가운데 하나가 보이면
    다음 16개를 붙인다(IntersectionObserver, 카드 스크롤에 가려진 행은 안 보이는 것으로 친다). 새 검색은 카드 맨 위부터, 검색을 지우면
    둘러보던 자리로 돌아간다
  - 검색 전 카드: 최근 검색어(있을 때만, 초점과 상관없이. 없으면 빈 상태 문장도 없다) + 과목 둘러보기(10/2 디자인). 둘러보기는 목록 머리의
    선택칸 `교양 전체 ▾`(이름 `과목 목록`, 학과 묶음은 학사 과목이 있는 학과 가나다)이 곧 목록 제목이고 카드 위에 붙어 있다. 행은 검색 결과
    행과 같다(강조 없이 학과 · 교과구분 · 학점). 학사 과목만, `교양 전체`는 가나다, 학과는 전필 → 전선 → 교양 → 그 밖(같은 묶음은 가나다).
    고른 목록은 `ttw.browse`(그 학기에 없는 학과면 `교양 전체`), 목록을 바꾸면 `과목 452개`를 읽는다. 폰에는 없다
- 과목 시트: 분반 켜고 끄기(`전체 선택`), 강의실 미정은 `강의실 미정 ▾`에서 건물을, 시간 미정은 `시간 추가`로 요일·시·분·건물을 넣는다
  (`type="time"` 을 쓰지 않는다). 넣지 않은 미정 수업은 이동·지각을 만들지 않는다
- 저장: 학기, 담은 과목(이름·교과구분·학점·학과도 함께), 분반 선택, 직접 넣은 강의실·시간은 학기마다, 조건과 최근 검색어(`ttw.recent`)·둘러보기 목록(`ttw.browse`)은
  한 벌을 브라우저(localStorage)에만 저장한다. 화면이 숨겨질 때 한 번 더 저장하고 입력 화면 스크롤도 돌려놓는다. 이번 자료에서 사라진 과목은 지우지 않고 `없는 과목` 태그를 달고
  계산에서 뺀다
- 시간 겹침: 담기·빼기·분반 켜고 끄기·직접 입력 때마다 켠 분반으로 겹치지 않는 조합이 있는지 바로 본다(50ms 안에 판단이 안 서면 만들 때).
  없으면 서로 막는 과목(가장 작은 묶음)의 담은 과목 행과 검색 결과 행(`✓ 담음` 앞, 좁으면 과목명 아래)에 `시간 겹침`, 담은 과목 제목 아래
  `겹치지 않는 조합이 없어요`. 원인이 풀리면 바로 사라진다
- 만들기: 담은 과목이 없거나 자료를 불러오기 전에만 버튼이 꺼진다. 분반을 모두 끈 과목은 그 행에 `켠 분반이 없어요`, 조합이 없으면
  `겹치지 않는 조합이 없어요`(위와 같다), 모르는 실패는 `시간표를 만들지 못했어요` [다시 시도].
  계산은 탐색 워커(`js/search-worker.js`)에서 돌아 화면이 멈추지 않는다. 500ms 안에 안 끝나면 버튼에 스피너와 `만드는 중`(200ms 이상 보임),
  10초를 넘을 것 같으면 진행 정도와 `취소`. 담은 과목·조건을 바꾸거나 다른 화면으로 가면 계산을 멈춘다. 워커를 못 쓰는 브라우저는
  화면 스레드에서 계산한다(조합 수 어림이 10만을 넘으면 스피너를 먼저 띄운다). 한 번에 20개 조합을 찾는다.
  전체 조합 수는 워커 결과의 `total = {count, exact}`(화면 스레드는 `countFeasible`)를 쓴다
- 결과: 요일 탭(수업 없는 날도 고를 수 있다) → 시간표 | 지도 → 교과구분 범례 → 하루 요약 `걷기 42분`(늦는 수업이 있으면 위험 태그 `2분 늦음`, 둘이면 `2분·5분 늦음`)
  → 목록 제목 → 후보 카드(6개씩 `더 보기`) → 추정 고지와 `자료 출처`. 점수·퍼센트는 보여 주지 않는다
- 목록 제목: 희미한 `(전체 조합 897개 중)`(16 `text3`) + `걷는 시간이 짧은 20개를 찾았어요`(`t-h2`), 오른쪽(좁으면 아래 줄)에
  `출발·도착 기숙사 919동 · 경사 반영`(기숙사만 동을 붙인다. 정문·다른 건물은 이름만). 두 덩이가 따로 줄을 바꿔 좁으면 희미한 쪽이 윗줄이다. 다 못 셌으면(`exact=false`) 어림수로
  `(1만 개가 넘는 조합 중)`(`3천 개`, `400개`처럼 내림). 찾은 것이 전부면(전체 수 ≤ 찾은 수) `전체 조합 4개를 찾았어요` 하나
- 시간표 높이: 한 시간이 `tt-hour-min` 32px(× 글자 배율)보다 낮아지지 않는다(10/2 디자인). 축(결과 전체의 가장 이른 시작~가장 늦은 끝)이 길어
  기본 높이 `--tt-h` 로 모자라면 모자란 만큼을 `#panes` 의 `--tt-extra` 로 준다(`sizeTimetable`): 시간 눈금·격자·시간표 카드·지도 카드가 같이
  늘어난다(폭 359px 이하로 쌓일 때는 시간표 카드만). 축은 결과 전체 것이라 요일·후보를 바꿔도 높이는 그대로다. 높이는 `#panes` 크기를
  기억하기 전에 정한다(뒤에 정하면 ResizeObserver 가 그 요일을 다시 그려 첫 결과의 경로 그리기가 끊긴다)
- 시간표 칸: 교과구분 연한 색 바탕에 과목명(끝의 부제 괄호는 뺀다)과 강의실 `301동 118호`(건물만 알면 `301동`, 직접 넣은 건물은
  `301동 (직접 입력)`). 과목명은 어느 칸이나 14px(10/2 사용자: 75분 칸에서 글자를 줄이지 않는다), 강의실은 늘 보인다(10/2 사용자: 공간이
  없으면 나란히라도). 쌓는 칸(38px 이상)은 강의실 줄을 두고 과목명은 남는 줄 수만큼(1–3줄), 낮은 칸(38px 미만, 50분 수업)은 과목명 옆에
  한 줄로(틈 `space-2`, 가운뎃점 없음) 두고 과목명이 먼저 세 글자까지 준다. 그래도 안 들어가면 호수를 빼고 건물만(`43-1동`).
  늦는 수업은 오른쪽 위 빨간 `2분 늦음`(마우스를 올리면 걷는 시간·쉬는 시간). 알약 자리는 다섯 단계다(디자인 규칙 '시간표 칸'):

## 배포

`.github/workflows/pages.yml` 이 main 에 푸시할 때와 수강편람 자동 갱신이 끝날 때마다 자료를 만들어 올린다.
처음 한 번 레포 Settings → Pages → Source 를 "GitHub Actions" 로 바꾼다.

배포할 때는 `export_web.py --stamp` 로 `index.html`·`js/app.js` 가 부르는 `style.css`·`app.js`·`engine.js` 주소에
판(`?v=<내용 해시>`)을 붙인다. GitHub Pages 는 파일을 10분 동안 서버에 다시 묻지 않고 쓰게 해서, 판이 없으면 배포 직후
새로고침한 화면에 옛 스크립트가 붙는다(새 화면 + 옛 동작. 2026-09-29 학기 선택을 올렸을 때 선택 줄이 안 보였던 까닭).
레포의 파일에는 붙이지 않는다. 로컬에서 `--stamp` 를 쓰면 그 두 파일이 바뀌니 되돌린다.
