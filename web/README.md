# web/

TT Wizard 화면. 정적 사이트라 서버 없이 돈다: `data/*.json` 을 읽고, 탐색은 브라우저에서 `js/engine.js`
(ttwizard 의 이동시간 행렬·평가·탐색을 옮긴 것)가 한다. 주소: https://archi142857.github.io/tt-wizard/ (Pages 를 켠 뒤)

- 디자인: TT Wizard 디자인 규칙 v3(공유 폴더 `디자인_시스템.md`, `design\v3\TT Wizard 디자인 규칙.md`). 색·간격·모서리·글자·모션 토큰은
  `style.css` 맨 위 `:root` 에 있고 이름은 디자인 시스템 `tokens.json` 과 같다. 컴포넌트는 디자인 시스템 `components/bundle.css` 를 옮긴 것이라
  클래스 이름도 같다(`.topbar`, `.course`, `dialog.sheet`, `.snackbar` …). 굵기는 400·500·700, 글자는 12px 이상, 글자 크기는 `rem`.
  단, 연도·학기 선택칸, 시간표 칸, 지도 번호표, 후보 카드는 사용자 요청(2026-10-01)으로 v2 모양을 v3 토큰으로 칠한 것이고,
  입력 화면 로고는 사용자 요청으로 워드마크만(`icons/wordmark.svg`, 디자인 세션 원본, 높이 `logo-topbar` 36px) 쓴다
- 다크 테마: 기기 설정(`prefers-color-scheme`)을 따른다. 다크 값은 `style.css` 의 `@media (prefers-color-scheme: dark)` 두 곳(토큰, 다크 전용 규칙)에
  있다. 로고는 `<picture>` 로 `wordmark-dark.svg`, 지도는 타일 층에만 필터를 건다. `theme-color` 는 라이트 `#EEF0FF`·다크 `#16171B`
- 화면은 입력 · 결과 · 정보 셋이고 전체 화면 지도, 자료 출처·오픈소스 라이선스가 그 위에 뜬다. 화면만 방문 기록(`pushState`)을 남겨
  시스템 뒤로 가기와 상단 바 뒤로가 한 단계씩 닫는다. 시트(과목, 이동시간 계산 방법, 홈 화면에 추가)는 `<dialog>` 라 Esc·Android 뒤로 가기로 닫힌다.
  새로 켜면 늘 입력 화면에서 시작한다
- 입력: 상단 바(워드마크, ⓘ 정보, 바탕은 좌우 여백까지 깔아 스크롤한 내용의 초점 테두리가 옆으로 비치지 않게, 오프라인이면 `오프라인` 태그, 웹 브라우저에서 첫 시간표를 만든 뒤 `설치`) → 연도·학기 선택칸 `2026년 ▾` `2학기 ▾`
  (편람이 있는 학기만. 연도를 바꾸면 같은 학기, 없으면 그해 마지막 학기. 지난 학기면 `지난 학기` 태그)과 `9월 30일 기준`
  → 검색(과목명·교과목번호·학과·교수, 초성 `ㅅㅁㅎ`, 교과목번호의 공백·마침표·대소문자 무시, 8개씩 `더 보기`. 행 어디를 눌러도
  담기·빼기이고, 담은 과목의 행은 어두운 바탕에 `✓ 담음`) → 담은 과목(제목 옆 `총 18학점`, 행을 누르면 과목 시트, ×로 빼면 되돌리기 스낵바, 아래에
  교과구분 색 풀이) → 조건(출발·도착, 이동시간) → 하단 `시간표 만들기`(폰에서 가상 키보드가 떠 있는 동안만 숨긴다. 초점이 아니라
  보이는 높이로 판단해서, 키보드를 내리면 검색창에 초점이 남아도 다시 보인다)
- 넓은 화면(840px~, 태블릿 가로·펼친 폴더블·PC): 입력 화면을 두 칸으로(`.input-left` 학기·검색 | `.input-right` 담은 과목·조건).
  `시간표 만들기`는 오른쪽 칸 맨 아래에 칸 폭으로 두고, 오른쪽 칸이 화면보다 길면 화면 아래에 붙는다(sticky). 그보다 좁으면 한 칸 + 하단 고정 바
  (되돌리기 스낵바는 넓은 화면에서 오른쪽 칸 폭으로 `시간표 만들기` 바로 위에 뜬다)
- 과목 시트: 분반 켜고 끄기(`전체 선택`), 강의실 미정은 `강의실 미정 ▾`에서 건물을, 시간 미정은 `시간 추가`로 요일·시·분·건물을 넣는다
  (`type="time"` 을 쓰지 않는다). 넣지 않은 미정 수업은 이동·지각을 만들지 않는다
- 저장: 학기, 담은 과목(이름·교과구분·학점·학과도 함께), 분반 선택, 직접 넣은 강의실·시간은 학기마다, 조건은 한 벌을 브라우저(localStorage)에만
  저장한다. 화면이 숨겨질 때 한 번 더 저장하고 입력 화면 스크롤도 돌려놓는다. 이번 자료에서 사라진 과목은 지우지 않고 `없는 과목` 태그를 달고
  계산에서 뺀다
- 시간 겹침: 담기·빼기·분반 켜고 끄기·직접 입력 때마다 켠 분반으로 겹치지 않는 조합이 있는지 바로 본다(50ms 안에 판단이 안 서면 만들 때).
  없으면 서로 막는 과목(가장 작은 묶음)의 담은 과목 행과 검색 결과 행(`✓ 담음` 앞, 좁으면 과목명 아래)에 `시간 겹침`, 담은 과목 제목 아래
  `겹치지 않는 조합이 없어요`. 원인이 풀리면 바로 사라진다
- 만들기: 담은 과목이 없거나 자료를 불러오기 전에만 버튼이 꺼진다. 분반을 모두 끈 과목은 그 행에 `켠 분반이 없어요`, 조합이 없으면
  `겹치지 않는 조합이 없어요`(위와 같다), 모르는 실패는 `시간표를 만들지 못했어요` [다시 시도].
  계산은 탐색 워커(`js/search-worker.js`)에서 돌아 화면이 멈추지 않는다. 500ms 안에 안 끝나면 버튼에 스피너와 `만드는 중`(200ms 이상 보임),
  10초를 넘을 것 같으면 진행 정도와 `취소`. 담은 과목·조건을 바꾸거나 다른 화면으로 가면 계산을 멈춘다. 워커를 못 쓰는 브라우저는
  화면 스레드에서 계산한다(조합 수 어림이 10만을 넘으면 스피너를 먼저 띄운다). 한 번에 20개 조합을 찾는다.
  전체 조합 수는 워커 결과의 `total = {count, exact}`(화면 스레드는 `countFeasible`)를 쓴다
- 결과: 요일 탭(수업 없는 날도 고를 수 있다) → 시간표 | 지도 → 교과구분 범례 → 하루 요약 `걷기 42분`(늦는 수업이 있으면 `늦을 수 있음`)
  → 목록 제목 → 후보 카드(6개씩 `더 보기`) → 추정 고지와 `자료 출처`. 점수·퍼센트는 보여 주지 않는다
- 목록 제목: 희미한 `(전체 조합 897개 중)`(16 `text3`) + `걷는 시간이 짧은 20개를 찾았어요`(`t-h2`), 오른쪽(좁으면 아래 줄)에
  `출발·도착 기숙사 · 경사 반영`. 두 덩이가 따로 줄을 바꿔 좁으면 희미한 쪽이 윗줄이다. 다 못 셌으면(`exact=false`) 어림수로
  `(1만 개가 넘는 조합 중)`(`3천 개`, `400개`처럼 내림). 찾은 것이 전부면(전체 수 ≤ 찾은 수) `전체 조합 4개를 찾았어요` 하나
- 시간표 칸: 교과구분 연한 색 바탕에 과목명(끝의 부제 괄호는 뺀다)과 강의실 `301동 118호`(건물만 알면 `301동`, 직접 넣은 건물은
  `301동 (직접 입력)`). 칸 높이에 맞춰 과목명을 먼저 보이고 남으면 강의실. 늦는 수업은 오른쪽 위 빨간 `2분 늦음`(마우스를 올리면 걷는 시간·쉬는 시간).
  알약은 과목명 첫 줄 옆에 들어가거나 가운데 놓인 글보다 위에 있으면 그대로 두고, 둘 다 아닐 때만 과목명 위에 한 줄을 둔다(과목명이 밀리지 않게).
  낮은 칸은 알약 자리만큼 과목명을 앞에서 말줄임
- 후보 카드: `1위` · `걷기 주 105분 · 월화수목 등교`(늦는 수업이 있으면 `· 늦을 수 있음`. 늦는 분을 한 주치 더한 값은 뜻이 없어 쓰지 않는다) · 요일별 미리보기(칸마다 교과구분 색 막대). 고른 카드는 파란 테두리와
  분반 목록. 넓은 화면(900px~)에서는 여러 열
- 분반 목록: 과목명 | 분반 두 열(행마다 subgrid 로 열을 맞춰 분반 번호를 세로로 훑게). 분반은 번호만 진하게(500 `text`), 교수는 `text3`.
  같은 시간·건물 분반은 아래 줄에 `같은 시간·건물`(과목명 열)과 그 분반(분반 열). 카드가 16em 보다 좁으면(작은 폰·큰 글자) 분반을 과목명 아래 줄로
- 지도: OpenStreetMap 타일 + Leaflet 1.9.4(`vendor/leaflet`, BSD-2). 선은 캠퍼스 마법 지도 그래프 위 경로(`data/routes.json`). 수업 가는 길은
  실선(흰 테두리), 마지막 수업 뒤 출발·도착 자리로 가는 길은 ⌂ 핀 색 파선(흰 테두리). 파선은 경로선 아래 칸에 진행 방향 오른쪽으로 7px
  비켜 그려서, 같은 길을 되짚어도 경로선을 덮지 않고 나란히 ⌂ 까지 보인다(배율이 바뀌면 다시 계산). 그 구간 시간은 `⌂ 19분`.
  핀 번호는 그날 수업 순서이고 지도 아래 번호표(번호 · 건물, ⌂ 출발·도착, 파선 견본 `기숙사 가는 길`)가 푼다. '돌아가는 길'은 우회로로도
  읽혀서 쓰지 않는다. 화면에서 겹치는 핀은
  `1·2`로 묶는다(확대·축소하면 다시 묶는다). 확대·축소: 마우스는 오른쪽 위 `+`·`−` 버튼·휠·끌기, 터치는 두 손가락(시간표 옆 작은 지도는
  한 손가락이 페이지를 스크롤하게 끌기를 끈다). `지도 크게 보기`는 전체 화면 지도(한 손가락으로 끈다). 저작권 표기 `© OpenStreetMap` 은
  지도 밖에 늘 보이게 두고, 타일을 못 받으면 왼쪽 위에 `지도 배경 없음`
- 분반·교수는 `061(나민애)` 로 적는다(교수가 없으면 `061(교수 미정)`)
- 스토어 앱: 어디서 도는지(`web`·`pwa`·`android`·`ios`)를 `<html data-shell>` 에 적고 설치 안내, 서비스 워커와 새 버전 알림, 외부 링크, 햅틱을 이 값으로 가른다.
  안드로이드·iOS 앱은 둘 다 Capacitor(`Capacitor.getPlatform()`): 서비스 워커·설치 안내·새 버전 알림이 없고 외부 링크는 Capacitor Browser,
  성공 햅틱은 iOS 만. 앱 연결 `js/native.js`(백엔드 몫, 빌드 때만 `<head>` 끝에)가 먼저 돌며 자료 받기·안드로이드 뒤로 가기·`data-platform` 을 맡는다.
  `index.html` 의 Pretendard `<link>`, `</head>`, `js/app.js` `<script>` 모양을 바꾸면 앱 빌드(`scripts/build_app.py`)가 멈추니 백엔드에 알린다.
  안전 영역은 `var(--safe-area-inset-*, env(safe-area-inset-*, 0px))`(옛 안드로이드 웹뷰는 Capacitor SystemBars 가 변수로 준다). 개인정보 처리방침·문의·스토어 주소는 `app.js` 맨 위 `PRIVACY_URL`·`CONTACT_URL`·`REVIEW_URL`
  (비어 있으면 정보 화면에 그 행이 없다). 버전은 `APP_VERSION`
- 폰 홈 화면 설치(PWA): `manifest.webmanifest` + `sw.js`. 서비스 워커는 같은 사이트 파일을 다루고(네트워크 먼저, 브라우저 캐시는 서버에
  바뀌었는지 물은 뒤에만, 3초 안에 안 오거나 끊기면 저장해 둔 것) 글꼴(CDN)은 한 번 받으면 저장해 두고 쓴다. 지도 타일·3D·2D 모델은
  다루지 않는다. 새 워커가 화면을 맡으면 입력 화면에서 `새 버전이 있어요` [새로고침]
- 시간·건물이 모두 같은 분반은 동선이 같으므로 하나로 묶어 찾고, 결과에 '같은 시간·건물' 분반으로 함께 적는다

## 로컬에서 보기 (cmd)

```
python scripts\slope_travel.py          (경로 모양 data\route_paths.json 이 없을 때만)
python scripts\export_web.py
python -m http.server 8000 -d web
```

브라우저에서 http://localhost:8000

## 파일

| 파일 | 내용 |
| --- | --- |
| `index.html`, `style.css` | 화면. `style.css` 맨 위가 디자인 시스템 토큰 |
| `manifest.webmanifest`, `sw.js`, `icons/` | 폰 홈 화면 설치(PWA). 앱 아이콘(`favicon.svg`, `favicon-32.png`, `apple-touch-icon.png`, `icon-192.png`, `icon-512.png`, `icon-maskable-512.png`)은 디자인 세션의 `design\v3\app-icons` 같은 이름 파일을 그대로 넣는다(10/1 새 심볼). 다크 판·`adaptive-*` 는 앱 포장용이라 웹에는 넣지 않는다(매니페스트 아이콘은 다크 판을 못 고른다). 화면 로고는 `wordmark.svg`·`wordmark-dark.svg`(`design\v3\logo\svg` 원본 그대로). 저장 방식을 바꾸면 `sw.js` 의 `CACHE` 이름을 올린다 |
| `js/engine.js` | 이동시간 행렬 · 평가 · 탐색(백트래킹 + 분기 한정) · 경로 선 풀기. 파이썬과 같은 답을 내는지 `tests/test_web.py` 가 node 로 확인 |
| `js/search-worker.js` | 탐색 워커: `engine.search` 를 화면 밖에서 돌리고 진행 정도·결과·겹치는 과목을 보낸다. `app.js` 가 `new Worker(new URL("./search-worker.js", import.meta.url), { type: "module" })` 로 부른다(배포 판이 붙는 모양) |
| `js/app.js` | 화면 동작(검색, 과목 시트, 화면 이동과 뒤로 가기, 결과·지도, 정보 화면). 담은 과목·조건·직접 넣은 강의실과 시간은 브라우저(localStorage)에만 저장 |
| `data/` | `scripts/export_web.py` 가 만든다. git 에는 올리지 않고, 배포 때 GitHub Actions 가 다시 만든다. `semesters.json`(학기 목록)과 `semesters/<학기>.json`(지난 학기) 포함 |
| `vendor/leaflet/` | Leaflet 1.9.4 (npm 배포본 그대로) |
| `model/` | 서울대학교 관악캠퍼스 3D·2D 모델링 (`scripts/campus_model.py` 가 만든 결과, 커밋한다) |
| `vendor/three/` | three.js r128 과 OrbitControls (npm 배포본 그대로, 3D 모델링용) |

## 배포

`.github/workflows/pages.yml` 이 main 에 푸시할 때와 수강편람 자동 갱신이 끝날 때마다 자료를 만들어 올린다.
처음 한 번 레포 Settings → Pages → Source 를 "GitHub Actions" 로 바꾼다.

배포할 때는 `export_web.py --stamp` 로 `index.html`·`js/app.js` 가 부르는 `style.css`·`app.js`·`engine.js` 주소에
판(`?v=<내용 해시>`)을 붙인다. GitHub Pages 는 파일을 10분 동안 서버에 다시 묻지 않고 쓰게 해서, 판이 없으면 배포 직후
새로고침한 화면에 옛 스크립트가 붙는다(새 화면 + 옛 동작. 2026-09-29 학기 선택을 올렸을 때 선택 줄이 안 보였던 까닭).
레포의 파일에는 붙이지 않는다. 로컬에서 `--stamp` 를 쓰면 그 두 파일이 바뀌니 되돌린다.
